## Welcome to the Find.ly API

The Find.ly API gives your scripts and servers the same searches as the [Find.ly dashboard](https://findly.icu/dashboard): leak records, selectors for a domain, raw files, stealer-log archives, and a person's records in our own breach index. It is a small JSON-over-HTTPS API with three endpoints, authenticated with one API key.

<Note>
  Full API access comes with the **Professional** and **Enterprise** plans. Professional gives 500 IntelX requests and
  2,000 Breach Search requests a day; Enterprise gives 1,500 and 5,000. **Starter** has API access to Breach Search only,
  with 500 Breach Search requests a day. See [pricing](https://findly.icu/#pricing).
</Note>

## Quick example

Check your key and both of today's quotas. This call is free: it never runs a search and never uses a request.

<CodeGroup>

```bash cURL
curl https://findly.icu/api/v1/usage \
  -H "Authorization: Bearer $FINDLY_API_KEY"
```

```python Python
import os
import requests

response = requests.get(
    "https://findly.icu/api/v1/usage",
    headers={"Authorization": f"Bearer {os.environ['FINDLY_API_KEY']}"},
    timeout=60,
)
print(response.json())
```

```javascript Node.js
const response = await fetch('https://findly.icu/api/v1/usage', {
  headers: { Authorization: `Bearer ${process.env.FINDLY_API_KEY}` },
});
console.log(await response.json());
```

</CodeGroup>

## How it works

- **One account, two quotas.** A key acts as your account. IntelX modules and Stealer Export draw from the daily **IntelX request** quota; Breach Search draws from its **own** daily bucket. The dashboard and the API share both, and the same per-account limits. See [Billing and quotas](/guides/billing-and-quotas).
- **Every response tells you what it cost.** JSON responses carry `billed` and a `usage` object for the quota the call drew from; JSON and text responses carry `X-Request-Billed`, and `X-Quota-*` headers whenever the quota is known.
- **Errors are free.** Invalid input, refused calls and service failures never use a request.
- **Server-side only.** The API sends no CORS headers: browsers cannot read its responses. Call it from a server, a script or a terminal, never from a web page.
- **Nothing is stored.** Results are sent back to you and not kept, so there is no server-side pagination: you get the whole list at once — up to 5,000 items from an IntelX module, up to 100 records from Breach Search. See [Pagination](/guides/pagination).

## Modules

Find.ly serves its own modules, from two sources:

- **IntelX Modules**, powered by our search provider Intelligence X: `intelligence-search`, `phonebook`, `identity-portal`, `system-id`, `storage-id`, plus the Stealer Export archive.
- **FindLy Module**: `breach-search`, which runs on a breach index Find.ly ingests and documents itself.

Stealer Export is **not** a search module: it answers with a file rather than JSON, so it has its own endpoint. See [Modules and inputs](/guides/modules) and [Stealer Export](/guides/stealer-export).

## Getting help

- **Your key, plan and quotas**: [Dashboard → API](https://findly.icu/dashboard/api). `GET /api/v1/usage` gives the same numbers from code, for free.
- **Something looks down**: the [status page](https://findly.icu/status) shows the state of each service and past incidents.
- **Anything else**: [contact us](https://findly.icu/contact). Include the endpoint, the time of the call and the `error.code` you received — never your API key.
